# BookingRoom — Сервис умного бронирования переговорок

**BookingRoom** — это внутренний сервис для гибридного офиса, который решает проблему неэффективного использования переговорных комнат. Вместо ручного поиска свободной комнаты в календаре, сотрудник указывает количество человек и нужное оборудование, а система сама подбирает идеальный вариант.

## Главные функции
* **Умный подбор:** Эндпоинт рекомендаций сортирует комнаты по принципу "минимально достаточного ресурса".
* **Защита от двойного бронирования:** Реализована на уровне базы данных PostgreSQL. Это гарантирует 100% целостность данных даже при одновременных запросах.
* **Ролевая модель (RBAC):** JWT-авторизация. Администраторы создают комнаты и видят все брони, сотрудники — только бронируют.

## Стек технологий
* **Backend:** Python 3.12, FastAPI, SQLAlchemy 2.0 (Async), Pydantic
* **Database:** PostgreSQL 16 (исп. расширение `btree_gist`)
* **Миграции:** Alembic
* **Frontend:** HTML5, Bootstrap 5, Vanilla JS
* **Инфраструктура:** Docker, docker-compose

## Как запустить локально
1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/zswk1r/bookingroom.git
   cd bookingroom
   ```

2. Создать виртуальное окружение и установить зависимости:
   ```bash
   python -m venv venv
   # Windows: .\venv\Scripts\activate
   # Mac/Linux: source venv/bin/activate
   pip install -r requirements.txt
   ```

3. Создать файл `.env` в корне проекта (скопировать содержимое из `.env.example`) и указать свои данные для подключения к PostgreSQL.

4. Применить миграции к базе данных:
   ```bash
   alembic upgrade head
   ```

5. Запустить сервер разработки:
   ```bash
   uvicorn app.main:app --reload
   ```

6. Перейти в браузере по адресу: `http://127.0.0.1:8000` (интерфейс) или `http://127.0.0.1:8000/docs` (Swagger).
